Quest 5: The Grand Trial

⚔️ The Final Boss

You have reached the end of the village path. Now you must face the Code Guardian. Every question is a spell test from everything you've learned so far.

What You Need to Know

  • Strings → Quotes matter ("5" vs 5)
  • Variables → Assignment & overwrite (x = 10 then x = 20)
  • Lists → Indexing (items[1])
  • Loops → Repeating actions
  • Functions → def and return

Boss Battle Rules

✅ Correct answer = Guardian HP decreases
❌ Wrong answer = You take damage
🏆 Reduce Guardian HP to 0 to win the trial.

Tip

Don’t rush. Read the code carefully. Most mistakes are small: brackets, quotes, and capital letters like Print().
